# 📚 Book Analysis Dashboard – Excel Project

## 📌 Project Overview

The **Book Analysis Dashboard** is an Excel-based data analytics project designed to analyze book-related data and generate meaningful business insights.

This dashboard provides an overview of book prices, user ratings, reviews, genres, authors, and publication years using KPIs, Pivot Tables, and charts.

The main objective of this project is to transform raw book data into meaningful visual insights that help users understand book trends and patterns.

## 🎯 Project Objectives

- Analyze book prices and identify the top 10 most expensive books.
- Understand the distribution of Fiction and Non-Fiction books.
- Analyze user ratings and reviews received by books.
- Explore book publication trends by year.
- Compare ratings across different genres and years.
- Analyze the number of ratings received by different authors.

## 📈 Dashboard Visualizations

The dashboard contains six major visualizations:

1. **Max Price Top 10 Books:** Identifies the 10 books with the highest prices.
2. **Distribution of Genre Books:** Shows the percentage distribution of Fiction and Non-Fiction books.
3. **Reviews Received by Books:** Displays the distribution of books across different rating ranges.
4. **Sum of Price by Year:** Analyzes the total book prices across different publication years.
5. **Count of Ratings by Year and Genre:** Compares Fiction and Non-Fiction book ratings across publication years.
6. **Count of Ratings by Author:** Identifies authors based on the number of user ratings.

## 🔍 Key Insights

- The dataset contains 550 books.
- The average user rating is approximately 4.62, indicating generally positive ratings.
- Non-Fiction books represent approximately 56% of the dataset.
- Fiction books represent approximately 44% of the dataset.
- The most expensive book is *Diagnostic and Statistical Manual of Mental Disorders, 5th Edition: DSM-5*, priced at 105.
- The dataset contains more than 6.5 million total reviews.
- The dashboard compares book ratings across different publication years and genres.
- Author-wise analysis helps identify authors receiving more user ratings.
